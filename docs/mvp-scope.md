# MVP Scope

This MVP is designed as a clickable demo, not a production-ready restaurant SaaS.

## Customer Side

- QR-based table page
- Branded café landing screen
- Menu categories
- Food item cards
- Item detail modal
- Add to cart
- Special instructions
- Place order
- Order success screen
- Basic order status

## Restaurant Side

- Dashboard overview
- Live orders board
- Kitchen display
- Menu management
- Table QR management
- Direct booking management
- Customer data screen
- Basic analytics

## Demo-Only Features

- Mock restaurant data
- LocalStorage/state-based order flow
- Fictional demo restaurant profile
- Clickable dashboard screens
- Simulated order, customer, booking, and analytics data

## Not Included in MVP

- Real payment gateway
- POS integration
- Inventory management
- Loyalty automation
- WhatsApp automation
- AI recommendations
- Multi-location system
- Production authentication and permissions

## Scope Principle

The MVP focuses on proving the customer experience and restaurant dashboard workflow before adding deeper backend systems.
