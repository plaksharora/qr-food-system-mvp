# Prompt Engineering Process

This project was created as a prompt-engineered MVP demo using Lovable.

The objective was not to manually code a production-ready SaaS. The objective was to translate a product idea into a structured AI build prompt and generate a clickable MVP prototype.

## Process Followed

1. Identified a real café/restaurant experience problem.
2. Defined the gap between QR menus and actual digital restaurant experience.
3. Broke the product into customer-side and owner-side workflows.
4. Defined the MVP scope and non-goals.
5. Created a fictional demo café: Saajh Café.
6. Wrote a detailed Lovable prompt covering product concept, routes, design direction, demo data, dashboards, customer flow, and future scope.
7. Used AI-assisted prototyping to generate the first clickable demo.

## Work Demonstrated

This repo is meant to demonstrate:

- product thinking
- structured prompt engineering
- UX flow planning
- MVP scoping
- AI-assisted prototyping
- documentation-first execution

## Honest Scope

This project should not be presented as a fully hand-coded application or production SaaS.

It should be presented as an AI-assisted MVP prototype created through structured prompting and product planning.
