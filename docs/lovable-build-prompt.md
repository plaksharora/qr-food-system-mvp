# Lovable Build Prompt Summary

This project was designed to be created through Lovable using a structured product prompt.

## Prompt Direction

Build a polished MVP demo web app called RestaurantOS.

The app should not be positioned as a basic QR menu. It should be positioned as a restaurant-owned branded digital food system.

## Demo Brand

Use one fictional demo restaurant: Saajh Café.

Saajh Café should feel warm, premium, modern Indian, calm, and café-specific. The digital experience should feel like an extension of the café’s physical ambience.

## Required Demo Modules

- Public landing page
- Demo selection page
- Customer QR ordering flow
- Menu browsing
- Cart and order placement
- Restaurant dashboard
- Live order management
- Kitchen display
- Table QR management
- Direct booking form
- Customer data screen
- Basic analytics screen
- Branding preview screen

## Important Non-Goals

Do not build production authentication, real payments, POS integration, inventory, WhatsApp automation, AI recommendations, or complex backend infrastructure.

The goal is a clickable MVP demo that communicates the product idea clearly.

## Honest Positioning

This is a prompt-engineered, AI-assisted prototype focused on product thinking, UX structure, and demo execution.
