# QR Food System MVP — Portfolio Case Study

## Project Type

Prompt-engineered MVP demo / AI-assisted product prototype.

This project was created to showcase product thinking, problem framing, UX flow planning, and structured prompt engineering. The focus is not manual full-stack coding. The clickable prototype was generated using AI-assisted development tools from a detailed product prompt and refined around a clear restaurant-tech use case.

## Problem Observed

Many cafés have shifted to QR menus, but most QR menus are still just PDF links. A customer scans the QR, opens the menu, checks the items, and still needs to call a waiter to place the order.

This means the menu became digital, but the restaurant experience did not.

Common friction points:

- Customers still wait for staff to take orders
- Orders can still be miscommunicated
- PDF menus are not always mobile-friendly
- The café's digital touchpoint often feels generic
- Restaurants do not capture useful direct customer data
- Bookings, orders, kitchen workflow, and analytics remain disconnected

## Core Insight

The QR code is not the product. It is only the entry point.

A better system would turn the QR into the doorway for a branded, restaurant-owned digital food system.

## Proposed Solution

A QR-based food system where the customer scans a table QR and enters the café's own branded digital ordering experience.

The customer can:

- Browse the menu visually
- View item details
- Add dishes to cart
- Customize basic instructions
- Place an order from the table
- Send the order directly to the kitchen/dashboard
- Book a table directly

The restaurant can:

- Manage orders from a dashboard
- View active kitchen workflow
- Manage menu items
- Create QR links for tables
- Capture direct booking requests
- View customer data
- Track basic analytics
